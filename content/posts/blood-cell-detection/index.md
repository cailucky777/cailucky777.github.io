**Authors**: **Savina (Luying) Cai**

Implements real-time blood cell detection using YOLOv8 for automated Complete Blood Count (CBC) analysis. The system identifies and classifies Red Blood Cells (RBC), White Blood Cells (WBC), and Platelets from microscopy images. Includes dataset preparation with Roboflow, model training with hyperparameter optimization, and evaluation using mAP metrics. Demonstrates clinical potential for automated hematology workflows.
