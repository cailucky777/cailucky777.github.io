**Authors**: **Savina (Luying) Cai**

Builds a machine learning classification pipeline for diabetes prediction using patient health indicators. Implements and compares multiple algorithms (Logistic Regression, Random Forest, SVM, XGBoost) with systematic hyperparameter tuning, cross-validation, and feature importance analysis. Addresses class imbalance through SMOTE and threshold optimization for clinically meaningful recall-precision tradeoffs.
