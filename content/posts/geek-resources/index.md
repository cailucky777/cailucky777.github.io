**Authors**: **Savina (Luying) Cai**

Designed and built a comprehensive open-source curriculum for K-12 computer science education, comprising 47+ files across 7 modules: Swift Fundamentals (10-week plan), SwiftUI App Development (8-week plan with 3 live demos), Unity Game Development (Roll-a-Ball, 2D Platformer), AR Development (ARKit/RealityKit), API Integration, and Competitive Programming (CCC/USACO prep). Includes lesson plans, runnable code demos, exercise sets with solutions, project ideas, and teacher templates. Used in real classroom settings.
