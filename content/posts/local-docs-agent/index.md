**Authors**: **Savina (Luying) Cai**

Built an end-to-end Retrieval-Augmented Generation (RAG) system using LangChain that loads local documents (PDF, Markdown, TXT), performs semantic chunking, generates embeddings via FAISS vector store, and answers natural language questions with source citations. The system demonstrates practical LLM application engineering including embedding pipeline design, retrieval strategy optimization, and context-window management for accurate, grounded responses.
