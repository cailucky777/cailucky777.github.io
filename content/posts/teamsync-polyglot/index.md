**Authors**: **Savina (Luying) Cai**

Architected a full-stack meeting intelligence platform using Next.js and TypeScript, integrating Google Gemma LLM for on-device inference. Features include real-time multilingual translation, AI-powered meeting transcription, intelligent note generation, and offline-first architecture. The system demonstrates end-to-end AI product engineering — from LLM integration and prompt design to responsive UI and deployment pipeline.
